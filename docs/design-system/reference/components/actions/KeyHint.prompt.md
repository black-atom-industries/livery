Keyboard-hint atom — key in subtle fg, uppercase action in hint fg; compose in a flex row with 18px gap for app footers.

```jsx
<KeyHint keys="j/k">NAVIGATE</KeyHint>
<KeyHint keys="⏎">APPLY</KeyHint>
<KeyHint keys="esc">BACK</KeyHint>
```

Every screen's footer lists its full key vocabulary with these.
